# Gemini3.us - AI Assistant Platform

A community-driven platform providing access to Google's Gemini 3 AI model through official API services.

## Features

- 🤖 **Gemini 3 Access** - Direct access to Google's latest AI model
- 🚀 **Fast & Reliable** - Optimized performance with 99.9% uptime
- 🔒 **Secure** - Enterprise-grade security through Google's infrastructure
- 🌐 **Multi-language** - Support for dozens of languages
- 💻 **Developer Friendly** - Easy API integration with comprehensive docs
- 🎨 **Modern UI** - Clean, responsive design built with React + Tailwind

## Tech Stack

- React 18.2+
- TypeScript 5.0+
- Vite 4.4+
- Tailwind CSS 3.3+
- React Router DOM 6.8+
- Framer Motion 10.16+
- Lucide React 0.263+

## Getting Started

### Prerequisites

Install pnpm if you haven't already:

```bash
npm install -g pnpm
```

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Visit http://localhost:3003

### Build

```bash
pnpm build
```

### Preview

```bash
pnpm preview
```
